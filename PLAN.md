## 1. Stack decision

**Recommended: Quarto (reveal.js) → published on GitHub Pages**

| Option | Pros | Cons |
|---|---|---|
| **Quarto + reveal.js** ✅ | Markdown source in git, matching the open, forkable curriculum we are pitching · speaker notes, fragments and timer · can embed the live `bia_curriculum` explorer in an iframe · figures generated by reproducible Python scripts · one `quarto publish gh-pages` (or a GitHub Action) gives a URL and QR code · PDF export for an offline backup (`decktape`) | Requires Quarto CLI · fine layout tweaks need some CSS |
| Raw reveal.js HTML | Full control, no build step | More boilerplate, harder to maintain and reuse |
| Google Slides | Easy co-editing and familiar | Not version-controlled, cannot embed the explorer live, cannot be generated reproducibly, no community PRs |
| Claude Slides artifact | Editable in the Claude app, exports to PPTX/PDF | Not on GitHub, so less "community-owned" |

**Repo layout:** a new repo `acorbat/globias2026-bia-curriculum-talk`, mirrored in this local folder:
```
_quarto.yml          # revealjs format, theme, footer, slide numbers
index.qmd            # the deck
theme/archipelago.scss   # colours from the map: red #D66977 (accent #D1495B) · yellow #EDB969 (accent #EDAE49) · teal #2F909F (accent #00798C) · greys
img/                 # archipelago.svg, screenshots, logos
figures/*.py         # scripts that generate the pitfall figures (PSF/size, uint8 overflow, saturation, projection)
refs/references.bib  # Tischer 2026, NEUBIAS, Bankhead, Sivagurunathan 2024, …
.github/workflows/publish.yml
```
**Backups:** a PDF on a USB stick and on the conference laptop, plus static screenshots of the explorer in case the Wi-Fi fails.

## 2. Storyline (one sentence)

*We all arrived at bioimage analysis from different islands. This leaves blind spots that can silently break analyses. Excellent teaching modules already exist, but there is no agreed chart of what every analyst must know. Let's draw that chart together with a common core plus electives, starting with a GloBIAS Working Group today.*

**Visual through-line:** your archipelago map. The three island colours code the pillars throughout the deck, and the map returns at the end, now with a charted common route.

### Part III-a — One concept, three islands (7:30 → 11:00) ✨ NEW

Each slide uses the same title, **"Resolution, explained to…"**, plus the island icon and colour. All three slides land on the same number (~200 nm), which is the point: the content is the same and only the way in differs.

| # | Slide | Content / visual | Time |
|---|---|---|---|
| 8 | **…a physicist** 🟨 (prism island) | Diffraction limits optical resolution. Formulas built as fragments: **Abbe** *d* = λ / 2NA · **Rayleigh** *r* = 0.61 λ / NA · axial ≈ 2λn / NA². Image = object ⊗ PSF (the OTF cuts off at 2NA/λ). Worked numbers: λ = 520 nm, NA 1.4 → *d* ≈ 186 nm, *r* ≈ 227 nm. Visual: an Airy pattern with its profile (generated in Python). | 1:00 (8:30) |
| 9 | **…a biologist** 🟦 (cell island) | Confocal image of tubulin-stained mouse embryonic fibroblasts (H. Vindin, CC BY 4.0, Wikimedia Commons). The cyan matches the biology island. A microtubule is ~25 nm wide, yet each filament in the image is about as wide as the diffraction limit (~200 nm), so roughly 8× wider. Zoomed inset of a single filament with a "25 nm to scale" bar. Consequences shown as fragments: width measurements reflect the PSF, not the biology · two filaments closer than ~200 nm merge into one (bundles and counting) · thin structures look dimmer. | 1:00 (9:30) |
| 10 | **…a research software engineer** 🟥 (computer island) | "The microscope runs `gaussian_filter` on reality." **Python animation** (done, ≈13.5 s): on the left, a Gaussian PSF kernel (σ ≈ 78 nm) **slides over** a 25 nm curved microtubule, and the light it collects is highlighted in yellow. On the right, the **camera pixels fill in one by one** with `image[i, j] = (object * psf_at(i, j)).sum()`, slowly for the first row and then faster, with an arrow linking kernel and pixel. Ending: `image = gaussian_filter(object, sigma=σ)`, with the real 25 nm line overlaid on the ~184 nm-wide band. | 1:30 (11:00) |

**Shared closing line (speaker notes, slide 10):** *"Three explanations, one learning outcome."* The NEUBIAS *Point spread function* module already defines that outcome: *"predict the impact of the PSF on quantitative measurements, including how it inflates object size and dilutes signal intensity."* The **core** fixes the outcome. **Bridges** adapt the way in.

### Assets for the resolution slides
- **Slide 10, done:** `figures/microtubule_psf_animation.py` → `microtubule_psf.mp4` (13.5 s, 1280×720, for a reveal.js `<video>`), `.gif` fallback, `_final.png` for the PDF export. Parameters: λ 520 nm, NA 1.4, σ = 0.21 λ/NA ≈ 78 nm (Gaussian approximation of a widefield PSF, Zhang et al. 2007 *Appl. Opt.* 46:1819), 65 nm camera pixels, 24×24-pixel field (1.56 µm). The finished image is exactly `gaussian_filter` sampled at pixel centres. Measured apparent width ≈ **184 nm** (≈ 7×), consistent with Abbe's 186 nm on slide 8. Noise and binning are left out to keep the message on the PSF.
